Админка KEC

Страница правит контент сайта и сохраняет его прямо в GitHub-репозиторий. Сайт остаётся статичным, GitHub Pages пересобирает его сам за 1–2 минуты после сохранения.

  1. Открой создание fine-grained токена
  2. Repository access → Only select repositories → lizaportfolio
  3. Permissions → Repository permissions → Contents: Read and write
  4. Скопируй токен и вставь ниже
Токен хранится только в этом браузере (localStorage) и никуда, кроме api.github.com, не отправляется.
